#Overview

Sentinel SOC Console is a Python web application for security investigations. A local Flask interface brings together Microsoft Entra ID audits, Sentinel and Defender XDR queries, IP reputation checks, and report generation. Long-running operations run as background jobs so their progress and status remain visible in the interface.

#Key features

  • Single-account and bulk Entra sign-in audits, including optional AbuseIPDB enrichment.
  • Entra ID Protection risky-user searches and follow-up sign-in investigations.
  • KQL queries against Microsoft Sentinel workspaces or Defender XDR Advanced Hunting.
  • IP intelligence from individual addresses, text files, or Sentinel Palo Alto IPS events, with optional Intigriti and AbuseIPDB checks.
  • HTML and CSV reports, plus TXT blocklists for IP investigations.
  • Optional per-user Entra authentication for multi-user deployments.

#Requirements

  • Python 3.10 or later.
  • Dependencies from requirements.txt: Flask, MSAL, Requests, urllib3, Cryptography, and Waitress.
  • Network access and the appropriate Microsoft Graph, Azure Log Analytics, or Azure Resource Manager permissions for the operations you use.

#Installation

From the project directory, install the dependencies:

bash
python -m pip install -r requirements.txt

#Usage

Start the local application with its Python entry point:

bash
python gui-soc.py

In local mode, open http://127.0.0.1:5000 in a browser. The interface lets you choose an investigation workflow, monitor its progress, and view or download saved reports.

#Security notes

The project README notes that third-party service credentials are currently configured in the source. Rotate any active credentials and move them to a secure store or external configuration before sharing or deploying the application. For shared deployments, follow the README's Entra, HTTPS reverse-proxy, host allowlist, and persistent-storage guidance. The README also flags disabled TLS verification in some outgoing requests as unsuitable for production.
